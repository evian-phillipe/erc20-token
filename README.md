# ERC-20 Token Contract

A Solidity ERC-20 token built with OpenZeppelin for portfolio and deployment demonstration.

## Features
- ERC-20 standard token
- Owner-only minting
- Maximum supply cap
- Initial supply on deployment

## Stack
- Solidity
- Hardhat
- OpenZeppelin
- Remix IDE
- Sepolia testnet
